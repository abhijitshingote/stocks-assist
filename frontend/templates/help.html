Reference

Concise, technical description of each page's business logic.

Conventions

Liquid universe (most screeners): price > $3, avg 10-day dollar volume > $10M, excludes Biotechnology. Sourced from the nightly stock_metrics table.
Market-cap buckets: Mega >$100B · Large $20–100B · Mid $2–20B · Small $200M–$2B · Micro <$200M.
Return fields: dr_1 / dr_5 / dr_20 / dr_60 / dr_120 = trailing 1/5/20/60/120-trading-day % return.
52W badge: shown when the latest day's high ≥ 99.5% of the trailing 252-day max high (server flag at_52w_high).
Stock-list row (all screeners): [★][#][TICKER][52W](mcap) … [1D%], with page-specific additive metrics on a second line.
Biotech exclude: default-on chip on every screener load (industry === Biotechnology, shared engine). Chip-off is session-only; reload re-applies the default.
Ticker exclude: abi_dislikes.json membership. kind=permanent or kind=temporary (expires_at = add + 30d). Applied in backend screener queries + daily_screener s1. Expired temps are not applied.
Weekly review cutoffs (WEEKLY_REVIEW_CUTOFFS in backend/app.py): loading…

Screeners

High Growth/high-sales-growth
main_view rows carrying the high_sales_growth tag — assigned when the average of the forward-pair TTM revenue-growth estimates exceeds 25%. Additive metric: forward revenue growth.
Daily Review/daily-review
Union of (1) stock_volspike_gapper rows with last_event_date = max OHLC date and (2) $200M+ names with dr_1 >= 1.5 × p90(mcap) where p90 ≈ 3.53 × (clip(mcap,$200M,$100B)/$100B)^-0.134 (60d median of p90(positive 1d) in a ±0.25 log10 window; flattens above $100B). Real bars: $100B+ +5.3%, $4B +8.0%, $0.5B +10.7%. Count floats with the tape. Default sort is mega-equivalent adjusted_dr_1 = dr_1 / (clip/100B)^-0.134; toggle switches to flat dr_1. List value is always raw dr_1; S/G chips only when event_today.
Vol Spike & Gaps/volspike-gapper
Stocks with volume-spike and/or gap events in the last 365 days (stock_volspike_gapper), grouped by event date (most recent first). Two-row items with event badges (type + magnitude).
Vol Spike & Gaps (W)/volspike-gapper-weekly
Same dataset and endpoint as /volspike-gapper; groups by ISO week (Monday start) of last_event_date instead of by day. Within a week, rows are ranked by an additive log-scale score (shown right-aligned, hover for the breakdown) rather than by date: 1.0·log2(1+ret/0.05) + 0.8·log10(mcap/1e9) capped at 3 + 0.4·log2(volRatio/3.5) capped at 1.5 (volume spikes only) + 0.4·(1−log2(events365)/3). Net effect: a size tilt (top-50 median cap ≈ $11B vs $1.5B for the full week) that still floats >40% moves on $1–3B names to the top, while names with many events in the trailing 365d are demoted.
Vol Spike & Gaps (M)/volspike-gapper-monthly
Group bucket is the calendar month of last_event_date (YYYY-MM). Ranking inside a month is re-weighted toward the current base instead of the event: 3.5·setup + 1.0·log10(mcap/1e9) capped at 2.5 + 0.3·move + 0.15·vol + 0.15·novelty. setup (0–1, from /api/VolspikeGapper-Setup, measured on the last 10 bars vs ema_10/ema_20/dma_50/dma_200) = 0.35·prox (distance to nearest MA in ATRs, 0→1, ≥1.5 ATR→0) + 0.25·tight (10-bar high-low range, ≤1.5 ATR→1, ≥3.5 ATR→0) + 0.20·hold (close position in that range, ≥0.9→1, ≤0.4→0) + 0.20·trend (above all 4 MAs→1, above ema_20 only→0.6). The chip on each row shows the nearest MA and the signed distance. Shares static/js/desktop/vsg-grouped.js with the weekly page, whose weights are unchanged.
Weekly Review/weekly-review
Live union of VSG 90d + Strong Stocks + Top 5D/20D + Fast RS. Extra row: one tinted pill per source with the native list number (VSG last_event_magnitude + date; STR adjusted_ti65; 5/20 dr_5/dr_20; RS rs_score). Color of the pill = source. The 4 source pages stay live. Queue hides watchlist, abi_trades.json, and abi_passes.json where cycle = current Saturday (ET) through Friday. Disposition: Pass / Watch / Buy / Short / Exclude. Default sort = adjusted_ti65 desc (nulls last). Toggle: Best rank / Adj TI65 / # sources / 1D / 5D. Cutoffs: WEEKLY_REVIEW_CUTOFFS — see Conventions above (fetched live).
Vol Spike & Gaps (90d)/volspike-gapper-90d
stock_volspike_gapper rows with last_event_date >= max(OHLC.date) − 90 calendar days. Flat list (no date grouping). Default sort is mega-equivalent adjusted_event_return = last_event_return×100 / (clip(mcap,$200M,$100B)/$100B)^-0.134 (same exponent as Daily Review; last_event_return is the event-day fraction). Toggle: Adj / monthly setup readiness (0–1 from /api/VolspikeGapper-Setup: 0.35·prox + 0.25·tight + 0.20·hold + 0.20·trend) / last_event_date descending (mcap then ticker as tiebreak). List value is raw event-day return; S/G + magnitude + event-date chip on the row. Volume ratio is not a sort key.
Strong Stocks/strong-stocks
Liquid universe (price ≥ $3, avg_vol_10d ≥ 50k, dollar_volume ≥ $10M) with a current TI65 = avg_close_7d / avg_close_65d. Default sort is adjusted_ti65 = (ti65 − 1) / (0.120 × (clip(mcap,$500M,$100B)/$100B)^-0.151) — one-shot p90(TI65−1) vs mcap, ±0.25 log10 window, liquid EX biotech, fit on $500M–$100B (MAPE 2.8%). Window p90 excess: $0.5B 0.25, $2B 0.23, $10B 0.17, $100B 0.12; mega rises (0.16/0.17 at $200B/$400B) so clip at $100B. Toggle: Adj / raw TI65 / monthly setup readiness (same setupParts as 90d; /api/StrongStocks-Setup covers the liquid TI65 universe). List value is raw TI65. No date/recency in the sort.
Top Returns/top-performance
Union of the top 30 names by each of dr_1, dr_5, and dr_20 (deduplicated).
Top 5D/20D/top-returns-5-20
Liquid universe (price ≥ $3, avg_vol_10d ≥ 50k, dollar_volume ≥ $10M). Membership is top 30 by adjusted_dr_5 ∪ top 30 by adjusted_dr_20 on All (not recomputed per cap). Cap tabs filter that union. Scales are one-shot p90(positive) vs mcap, ±0.25 log10 window, liquid EX biotech, fit on $500M–$100B: adjusted_dr_5 = dr_5 / (clip(mcap,$500M,$100B)/$100B)^-0.192 (MAPE 12.6%; window p90: $0.5B 28.6, $2B 16.2, $10B 13.0, $100B 10.0); adjusted_dr_20 = dr_20 / (clip/$100B)^-0.177 (MAPE 8.4%; p90: $0.5B 58.8, $2B 38.0, $10B 25.8, $100B 21.5). Clip lo $500M (no liquid micro); clip hi $100B (mega p90 does not keep falling). Do not reuse Daily Review -0.134. Default sort is mega-equivalent adjusted_dr_5; toggle: Adj 5D / flat dr_5 / monthly setup readiness (same setupParts as 90d / Strong Stocks; /api/StrongStocks-Setup). List value is always raw dr_5; 5/20 chips mark which set a name came from. Distinct from /top-performance (raw 1d∪5d∪20d, no mcap scale).
Top Losers/top-losers
Union of the bottom 30 names by each of dr_1, dr_5, and dr_20 (deduplicated).
All Stocks/all-stocks
The full liquid universe with no ranking filter — only sector/industry filtering (plus the shared Biotech exclude chip). Baseline dataset behind the other screeners.
Technical/technical-screener
Intraday setups computed from the latest OHLC bar. Current criterion — reversal: low-to-close recovery, (close − low) / low × 100, top 100 descending. Additive metric: criterion value.

Relative Strength

Slow/Fast RS/rs-screener
Multi-timeframe relative-strength ranks (2D/5D/10D/20D/60D). Fast mode = slider-weighted composite of those ranks; Slow mode = IBD-style RS rating. Additive metric: RS rating (slow) or composite score (fast).
Fast RS/fast-rs
Clone of Slow/Fast RS Fast mode. Frozen weights 10/25/50/50/50 on raw rs_2d/5d/10d/20d/60d (excess % vs SPY), not bucket NTILE ranks. rs_score = (10·rs_2d + 25·rs_5d + 50·rs_10d + 50·rs_20d + 50·rs_60d) / 185. Default sort is TI65-style adjusted_rs_score = rs_score / (13.66 × (clip(mcap,$500M,$100B)/$100B)^-0.192) — one-shot p90(positive rs_score) vs mcap, ±0.25 log10 window, liquid EX biotech, fit on $500M–$100B (MAPE 8.2%). Window p90: $0.5B 32.7, $2B 32.3, $10B 19.9, $100B 14.4; mega rises (15.3/19.3 at $200B/$400B) so clip at $100B. Do not reuse Daily Review -0.134 or TI65 -0.151. Toggle: Adj RS vs monthly setup readiness (same setupParts as Strong Stocks; /api/StrongStocks-Setup). List value is raw rs_score. No sliders, no Slow RS, no SPY subchart. Shared − Biotech chip.
Sector Performance/sector-performance
Index/sector-ETF performance across 1D/5D/20D/60D/120D timeframes.

Personal (Abi)

Abi Watchlist/abi-watchlist
Personal watchlist (user_data/abi_watchlist.json) rendered with the Main View layout and metrics. Membership hides the ticker from /weekly-review until removed.
Trades/abi-trades
Buy/short candidates (abi_trades.json, side=buy|short). Persistent. Hidden from /weekly-review while listed.
Abi General Notes/abi-general-notes
Free-form, date-based personal notes with tags. Independent of any ticker. Per-ticker markdown lives in the Abi ticker notes modal (abi_ticker_notes.json). Short on-chart labels are separate (abi_chart_notes.json) — click the chart identity overlay, ≤5 lines × 80 chars.
Dislikes/abi-dislikes
Global exclude list (abi_dislikes.json). kind=permanent or kind=temporary (30d via expires_at). Applied to all screener queries + daily_screener s1. Optional rationale in ticker notes.
Main View/main-view
Combined universe view joining metrics, volspike/gapper events, and computed tags (high_sales_growth, TI65, recent volume-spike/gapper).

Daily Pipeline

Daily Shortlist/daily-shortlist
AI-scored daily candidate set per date, split into Picks / Watch / Rejected tabs, with per-ticker feedback capture. Reads the audit artifact produced by the shortlist pipeline run.
Daily Themes/daily-themes
Visualizes the theme vector for a given pipeline run — the composite theme weights plus the per-source raw lists that fed them.
Themes/themes
Curated thematic watchlists (user_data/themes.json) shown side-by-side; editable, with backend-suggested discovery proposals.

Market Context & Ops

Context/context
Market context: QQQ/SPY charts with moving-average (DMA) analysis.
Context-2/context-2
Research links, running commentary, and upcoming calendar/economic events.
ETFs/etfs
Curated thematic / sub-sector ETF groups with performance across 1D/5D/20D/60D/120D (user_data/etfs.json).
Market Brief/market-brief
Daily AI-generated market summary per date, with run cost tracking and PDF export. Includes an R1D losers brief variant.
Market News/market-news
Aggregated market-wide news from FMP, Seeking Alpha, and Benzinga.
Logs/logs
Viewer for nightly data-pipeline log files (update runs, successes/failures, durations).
Stock Detail/stock/<ticker>
Per-ticker deep dive: price chart with event markers, earnings/EPS history, analyst estimates, TTM ratios, company profile, and merged news. Reachable via the nav ticker search. Chart notes (short labels under name/sector, abi_chart_notes.json) are edited by clicking the identity overlay; they stay visible with no extra click.
