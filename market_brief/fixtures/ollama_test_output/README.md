## If something looks wrong

1. **Stale mixed runs** — Filenames like `*_qwen3_30b.md` and `*_gemma4_latest.md` from different runs can coexist. Use `--clean` for a fresh directory.

2. **`Connection refused` in a `.md` file** — Old bug: errors were written into `.md`. Re-run; errors now go to `*.error.txt` only.

3. **`results.json` incomplete** — Only reflects the **last** run. It previously had only `gemma4:latest` because `DEFAULT_MODELS` was temporarily set to that.

4. **Missing tickers (e.g. POET)** — Multi-ticker whale articles list 10 names; models often summarize only the first few unless the prompt forces per-ticker coverage (updated in script).

5. **Wrong `[chatter]` tags** — Benzinga scanner text should be `[confirmed]`, not `[chatter]`.
